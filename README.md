# Organizador imposto 💵💰
Este projeto foi desenvolvido durante um curso da DIO com o objetivo de explorar os recursos do Microsoft Excel na construção de uma planilha automatizada para organizar informações financeiras e pessoais utilizadas na preparação da declaração do Imposto de Renda.

A solução busca centralizar informações relevantes, facilitando a consulta e a organização dos dados ao longo do processo.

---

## 🎯 Problema de Negócio

A falta de organização de documentos e informações financeiras pode dificultar a preparação da declaração do Imposto de Renda, especialmente quando os dados são reunidos apenas próximo ao prazo de entrega.

Nesse contexto, uma planilha estruturada pode auxiliar contribuintes e profissionais de contabilidade a manter as informações organizadas, facilitar a consulta aos registros e reduzir o trabalho de reunir dados dispersos.


> **Pergunta central:**  Como uma planilha automatizada no Excel pode contribuir para a organização das informações e agilizar a preparação da declaração do Imposto de Renda?

---

## 💡 Impacto Esperado

Os resultados desta análise permitem à equipe de crédito:

- **Centralizar informações** Reunir dados para facilitar o acesso e a consulta.
- **Agilização do processo** Reduzir o tempo de organização das informações.
- **Apoio à rotina contábil** facilitar o acompanhamento dos dados fornecidos pelos clientes.
- **Redução de falhas operacionais** Minimizar esquecimentos durante a preparação dos dados.

---

## 📋 Metodologia

### 1. Compreensão do problema de negócios
- Identificação das dificuldades relacionadas à organização das informações.
- Definição dos objetivos da planilha.

### 2. Estruturação dos dados
- Organização das informações em tabelas e categorias.
- Definição da estrutura para facilitar o registro e a consulta dos dados.

### 3. Implementação da automação
- Utilização de fórmulas e recursos do Excel para automatizar operações previstas na planilha.
- Aplicação das regras definidas para o funcionamento da solução.

### 4. Testes e validação
- Verificação dos resultados apresentados após alterações nos dados de entrada.
- Conferência do funcionamento das fórmulas e dos recursos implementados.

### 5. Ajustes de usabilidade
- Organização visual das informações.
- Ajustes de cores, formatação e disposição dos elementos para facilitar a utilização.
